Welcome to my little corner of the web.

I wanted a place that is properly mine — not a profile on someone else's
platform — where I can introduce myself and occasionally write about software
development. This is that place.

## How it's built

The site is built with [Astro](https://astro.build), a web framework designed
for content sites. A few things I like about it so far:

- **Posts are just Markdown files.** Writing a new post means adding one `.md`
  file to a folder — no database, no admin panel.
- **It ships almost no JavaScript.** Pages load fast because Astro renders
  everything to plain HTML at build time.
- **It's easy to host.** The whole site compiles to static files that can live
  on GitHub Pages for free.

## What to expect here

I don't plan to post often. When I do, it will be practical things: notes on
C#, Angular, and whatever I happen to be learning or debugging at work.

Thanks for stopping by.
